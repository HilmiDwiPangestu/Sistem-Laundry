03

Printer Thermal

Pilih jalur cetak sesuai koneksi dan protokol printer.

1Driver Windows / BrowserMode paling kompatibel untuk USB atau Bluetooth yang sudah dipasangkan di Windows. Pilih printer saat dialog cetak muncul.
2ESC/POS langsung di WindowsJalankan Printer Bridge jika printer mendukung data RAW ESC/POS. Mode ini mengirim teks, bukan gambar/logo.
3Bluetooth Android (BLE)Gunakan Chrome Android melalui HTTPS. Hanya printer BLE yang membuka karakteristik tulis yang didukung.
4Bluetooth klasik / SPPBrowser tidak bisa mengakses SPP langsung. Gunakan aplikasi layanan cetak Android atau aplikasi resmi printer, lalu cetak dari browser.
Catatan

Gunakan Cetak via Driver/Browser sebagai pilihan utama. Printer Bridge lokal dan BLE merupakan opsi langsung yang bergantung pada dukungan protokol printer. Jika hasil cetak tidak benar, kembali ke mode driver/browser.

04

Printer Lokal Windows

Cetak ESC/POS langsung melalui antrean printer di komputer kasir.

Token disimpan hanya di browser ini, bukan ke database aplikasi.

Aktivasi pertama kali

Di komputer kasir Windows, jalankan start_printer_bridge.bat. Salin token yang tampil di jendela hitam ke kolom di atas. Pastikan printer sudah muncul di Windows. Mode ESC/POS mengirim teks mentah, jadi gunakan hanya jika printer mendukung ESC/POS RAW; bila tidak, pilih Cetak melalui Driver/Browser.
